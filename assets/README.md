# Assets

| File | Purpose | In repository |
|------|---------|---------------|
| `logo.png` | Logo shown in the window header | yes |
| `icon.png` | Application / taskbar / Dock icon (≥ 512 px, square) | yes |
| `log_animation.gif` | Optional animation docked left in the log panel (Rainbow theme only) | **no** – add your own locally, it is git-ignored |

Replace `logo.png` and `icon.png` with your own branding if you fork the
project. The build scripts convert `icon.png` to `.ico` / `.icns` automatically.
